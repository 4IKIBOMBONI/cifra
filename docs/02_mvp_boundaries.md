# 2. Границы MVP

## Входит в MVP (первая рабочая версия)

### Регистрация и авторизация
- Регистрация студента с верификацией по ФИО + номер студенческого билета
- JWT-авторизация (access + refresh токены)
- Ошибка верификации с редиректом на Telegram-бот поддержки
- Ручное заведение школьников/гостей администратором
- Профиль пользователя с аватаром и основными данными

### Направления и ресурсы
- Каталог направлений (киберспорт, лазертаг, дроны, PlayStation, компьютерные места)
- Карточки оборудования и площадок с описанием и фото
- Привязка ресурсов к локациям

### Бронирование
- Расписание слотов по направлениям с фильтрацией по дате
- Индивидуальное бронирование
- Командное бронирование (создание команды, приглашение участников)
- Открытые слоты (запись любого желающего)
- Слоты 30 мин / 1 час / 2 часа
- Отмена без штрафа за 24 часа
- Подтверждение посещения тренером
- Настраиваемая вместимость слотов по направлениям

### Рейтинг и баллы
- Единая рейтинговая система (баллы = рейтинг в v1)
- Начисление за посещение, участие, достижения
- Снятие за неявку, позднюю отмену, нарушения
- Влияние рейтинга на лимит бронирований
- История изменений рейтинга с причинами
- Уведомления об изменении рейтинга
- Страница с правилами начисления

### Награды
- Каталог наград (мерч, подарки партнёров)
- Остатки / наличие
- Обмен баллов на награды
- История начислений и списаний

### Турниры и новости
- Лента новостей
- Анонсы турниров (дата, место, формат, направление)
- Публикация результатов турниров как постов
- Теги и категории

### Обучающие материалы
- Каталог материалов по направлениям
- Поддержка текста, PDF, видео, ссылок
- Поиск и фильтрация

### Карта кампуса
- 2D-схема кампуса (SVG/растр)
- Точки активностей на карте
- Переход от точки к информации о локации и далее к бронированию

### Профиль кандидата ДКШ
- Анкета: описание, навыки, интересы, достижения, направления, опыт, контакты
- Просмотр анкет администратором
- Фильтрация кандидатов по направлениям

### Администрирование
- Управление пользователями (подтверждение, блокировка, ручное создание)
- Управление слотами, оборудованием, направлениями, локациями
- Публикация новостей и анонсов
- Управление рейтингом (ручная корректировка)
- Управление каталогом наград
- Аналитика (дашборд с ключевыми метриками)
- Выгрузка Excel и PDF
- Журнал действий (audit log)

### Уведомления
- In-app уведомления (внутри платформы)
- Интеграция с Telegram-ботом для критичных уведомлений

---

## Откладывается на следующие этапы (v2+)

| Функция | Причина откладывания |
|---------|---------------------|
| Автоматическая турнирная система (сетки, матчи, расчёт) | Сложная логика, на старте достаточно анонсов |
| Разделение рейтинга и баллов на отдельные сущности | В v1 работают как одна; архитектура готова к разделению |
| Тесты и сертификаты по материалам | Не влияют на допуск к бронированию |
| Сложная геонавигация по кампусу | Достаточно статичной 2D-схемы |
| Push-уведомления (PWA / мобильное приложение) | In-app + Telegram покрывают потребности |
| Многоуровневые роли администраторов | На старте все админы равноправны |
| Интеграция с внешними системами ВУЗа (деканат, БРС) | Требует согласований и API со стороны ВУЗа |
| Платёжная система | Награды выдаются за баллы, не за деньги |
| Мобильное нативное приложение | Адаптивный веб покрывает потребности |
| Система рекомендаций | Требует данных о поведении пользователей |

## Сознательно не делается на старте

- Очередь ожидания на слоты — не нужна по ТЗ
- Штрафы за отмену менее чем за 24 часа — отмена просто блокируется
- Автоматический подбор кандидатов для ДКШ — достаточно ручного просмотра
- Оценка тренеров студентами — не в скоупе
- Чат/мессенджер внутри платформы — используется Telegram
- Мультиязычность — платформа только на русском
- Тёмная тема — одна визуальная тема
