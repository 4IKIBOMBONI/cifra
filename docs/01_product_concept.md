# 1. Продуктовая концепция платформы «CIFRA»

## Позиционирование

CIFRA — внутренняя цифровая платформа СГТУ для управления фиджитал-активностями университета. Объединяет киберспорт, лазертаг, дроны, PlayStation и компьютерные тренировочные места в единую экосистему с бронированием, геймификацией и рейтинговой системой.

## Основная ценность

Единая точка входа для студента во все физические и цифровые активности университета: от записи на тренировку до участия в турнирах и получения наград. Для администрации — полная прозрачность загрузки ресурсов, посещаемости и вовлечённости.

## Ключевые задачи системы

1. **Цифровизация доступа** — заменить бумажные журналы, чаты и устные договорённости на структурированное бронирование с подтверждением.
2. **Мотивация через геймификацию** — рейтинговая система стимулирует посещаемость, дисциплину и активное участие.
3. **Управление ресурсами** — учёт оборудования, площадок, слотов и загрузки в реальном времени.
4. **Формирование кадрового резерва** — профили кандидатов для ДКШ позволяют находить наставников среди студентов.
5. **Информирование** — новости, анонсы турниров, обучающие материалы в одном месте.
6. **Аналитика** — данные для принятия решений по развитию направлений.

## Целевые группы пользователей

| Группа | Описание | Мотивация |
|--------|----------|-----------|
| Студент | Основной пользователь. Верифицируется через студенческий билет | Доступ к активностям, рейтинг, награды, развитие |
| Школьник / гость | Ограниченный доступ. Заводится вручную через администратора | Знакомство с университетом, просмотр расписания |
| Тренер / организатор | Ведёт занятия, подтверждает посещения, управляет слотами | Управление группами, отчётность |
| Администратор | Полный доступ к управлению платформой | Контроль, аналитика, управление контентом |

## Почему этот продукт жизнеспособен

1. **Реальная боль** — сейчас бронирование и учёт ведутся через мессенджеры и таблицы, что неэффективно при масштабировании.
2. **Готовая аудитория** — студенты СГТУ уже пользуются фиджитал-площадками, платформа систематизирует существующий процесс.
3. **Расширяемость** — архитектура на основе «направлений» позволяет добавлять любые секции без переработки системы.
4. **Фиджитал-тренд** — соответствует федеральной повестке развития фиджитал-спорта в вузах.
5. **Кадровый конвейер** — профиль кандидата в ДКШ решает задачу подбора наставников для работы с детьми.
