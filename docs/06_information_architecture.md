## Основные разделы навигации

### Десктоп — верхняя навигационная панель

```
┌─────────────────────────────────────────────────────────────────────┐
│ [CIFRA logo]  Направления  Расписание  Рейтинг  Новости  Материалы │
│                                           Карта  Награды            │
│                                    [🔔 3]  [Аватар ▾ 156 pts]     │
└─────────────────────────────────────────────────────────────────────┘
```

**Левый блок**: логотип (ссылка на главную), основные разделы.
**Правый блок**: уведомления (колокольчик с счётчиком), аватар с выпадающим меню (профиль, мои бронирования, команды, ДКШ, выход), рейтинг (число баллов).

Для админа и тренера: дополнительный пункт «Админ» / «Мои занятия» в выпадающем меню.

### Мобильная навигация — нижний таб-бар + бургер

```
┌─────────────────────────────────────────────────┐
│ [CIFRA]                        [🔔]  [☰ меню]  │  ← шапка
├─────────────────────────────────────────────────┤
│              [контент страницы]                  │
├─────────────────────────────────────────────────┤
│  🏠       📅       ⭐       📰       👤        │  ← таб-бар
│ Главная Расписание Рейтинг Новости Профиль      │
└─────────────────────────────────────────────────┘
```

**Таб-бар** (5 вкладок): Главная, Расписание, Рейтинг, Новости, Профиль.
**Бургер-меню**: все остальные разделы (Направления, Материалы, Карта, Награды, Команды, ДКШ).

## Логика навигации

### Десктоп
- Навигация через верхнюю панель — все разделы в один клик.
- Админ-панель — отдельный layout с боковым меню.
- Breadcrumbs на вложенных страницах: `Направления > Киберспорт > CS2`.

### Мобильная версия
- Основные действия — через таб-бар (5 разделов).
- Дополнительные разделы — через бургер-меню (выезжает слева).
- Карточки в каталогах — вертикальный список вместо сетки.
- Таблицы — горизонтальная прокрутка или карточный вид.
- Модальные окна — полноэкранные на мобильных.

### Переходы между сущностями
- Направление → расписание этого направления → бронирование слота
- Карта → локация → расписание этой локации → бронирование
- Профиль → мои бронирования → карточка слота → отмена
- Новость (анонс турнира) → направление → расписание
- Награда → запрос → история в профиле
