# 12. Итоговый стек технологий

## Frontend

| Технология | Назначение | Обоснование |
|-----------|------------|-------------|
| React 18 | UI-фреймворк | Зрелая экосистема, компонентный подход, большое комьюнити |
| TypeScript | Типизация | Безопасность типов, автодополнение, меньше багов |
| Vite | Сборка | Быстрый dev-сервер, HMR, оптимизированный билд |
| React Router v6 | Роутинг | Стандарт для React SPA, lazy loading |
| TanStack Query | Серверное состояние | Кэширование, рефетчинг, пагинация, мутации |
| Zustand | Глобальное состояние | Минималистичный, без boilerplate |
| React Hook Form + Zod | Формы + валидация | Производительность, декларативная валидация |
| TanStack Table | Таблицы (админ) | Headless, серверная пагинация/сортировка |
| Tailwind CSS | Стилизация | Utility-first, быстрая разработка, адаптивность |
| Recharts | Графики (аналитика) | Простой API, React-нативный |
| react-zoom-pan-pinch | Карта кампуса | Масштабирование и перемещение SVG |
| Axios | HTTP-клиент | Интерцепторы, удобная работа с токенами |
| date-fns | Работа с датами | Легковесная, tree-shakeable |

## Backend

| Технология | Назначение | Обоснование |
|-----------|------------|-------------|
| Python 3.12 | Язык | Быстрая разработка, богатая экосистема |
| FastAPI | Web-фреймворк | Async, автодокументация (Swagger), Pydantic-валидация |
| SQLAlchemy 2.0 | ORM | Зрелая ORM, поддержка async, миграции |
| Alembic | Миграции БД | Стандарт для SQLAlchemy |
| Pydantic v2 | Валидация данных | Быстрая, интегрирована с FastAPI |
| python-jose | JWT | Генерация и валидация токенов |
| bcrypt (passlib) | Хеширование паролей | Безопасное хеширование |
| python-telegram-bot | Telegram-бот | Зрелая библиотека, async |
| openpyxl | Excel-экспорт | Генерация .xlsx |
| reportlab | PDF-экспорт | Генерация PDF-отчётов |
| python-multipart | Загрузка файлов | Для FastAPI file uploads |
| uvicorn | ASGI-сервер | Быстрый, production-ready |

## БД

| Технология | Назначение | Обоснование |
|-----------|------------|-------------|
| PostgreSQL 16 | Основная БД | Надёжность, JSONB, производительность |
| Redis | Кэш, сессии | Кэширование аналитики, refresh-токены, rate limiting |

## Auth

| Технология | Назначение |
|-----------|------------|
| JWT (access + refresh) | Stateless-аутентификация |
| Access token | 15 минут, в памяти на фронтенде |
| Refresh token | 7 дней, httpOnly cookie |
| bcrypt | Хеширование паролей |

## Файлы / медиа

| Технология | Назначение | Обоснование |
|-----------|------------|-------------|
| MinIO (S3-compatible) | Хранение файлов | Self-hosted, S3 API, бесплатный |
| Альтернатива: локальная ФС | Для простого старта | Можно начать с /uploads и мигрировать на MinIO |

Решение: на старте — локальная ФС (`/uploads`), с абстракцией в коде для миграции на S3.

## Хостинг / деплой

| Компонент | Решение |
|-----------|---------|
| Сервер | VPS (2+ vCPU, 4+ GB RAM) — Timeweb, Selectel или университетский сервер |
| Reverse proxy | Nginx |
| SSL | Let's Encrypt (certbot) |
| Контейнеризация | Docker Compose (PostgreSQL, Redis, Backend, Frontend, Nginx) |
| Мониторинг | Grafana + Prometheus (опционально, v2) |
